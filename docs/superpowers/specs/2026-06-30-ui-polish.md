# Code2Flow UI Polish — Design Spec

**Date:** 2026-06-30
**Status:** Approved
**Scope:** Holistic visual polish across all pages — landing, dashboard, editor toolbar, auth. No color system changes (keep dark navy / white primary). Aesthetic target: clean minimal SaaS (Linear/Vercel style).

---

## Foundation (Global)

- **Colors:** Unchanged — `--background: 222.2 84% 4.9%`, white primary, existing shadcn tokens.
- **Icons:** Replace all text-only icon-adjacent labels with paired Lucide React SVG icons. No emojis. Consistent stroke width (Lucide default 1.5px).
- **Transitions:** All hover states use `transition-colors duration-150` or `transition-all duration-150`. Ease-out.
- **Spacing rhythm:** 4/8px increments throughout. No arbitrary values.
- **Icon library:** `lucide-react` (already installed as shadcn dependency).

## Section 1 — Landing Page (`app/page.tsx`)

### Hero
- Headline: `text-6xl font-bold tracking-tighter` (up from `text-5xl font-bold tracking-tight`)
- Key word "instantly" gets `underline decoration-primary/40 underline-offset-4` — emphasis without color change
- Subtitle: tighten container to `max-w-xl` (was `max-w-2xl`) for ~65 char line length
- CTA gap: `gap-4` (was `gap-4`, keep as-is; primary button padding confirmed `size="lg"`)

### Feature Cards (3-up grid)
Replace plain `border rounded-lg p-6` with:
- Icon row: small Lucide icon above the heading
  - "Instant preview" → `Zap` (16px, `text-muted-foreground`)
  - "Version history" → `Clock`
  - "Public sharing" → `Share2`
- Card surface: `bg-muted/40 hover:bg-muted/60 transition-colors`
- Border: `ring-1 ring-border/50` (replaces solid `border`)
- Padding: keep `p-6`
- Icon margin-bottom: `mb-3` before heading

## Section 2 — Dashboard (`app/(protected)/dashboard/page.tsx` + `components/dashboard/FlowchartCard.tsx`)

### FlowchartCard
- **Top accent strip:** `border-t-2` colored by language:
  - `javascript` → `border-amber-500`
  - `typescript` → `border-blue-500`
  - `python` → `border-green-500`
  - fallback → `border-border`
- **Card surface:** `bg-card shadow-sm hover:shadow-md transition-all duration-150`
- **Border:** keep `rounded-lg border` but add `hover:border-primary/50`
- **Date:** replace `toLocaleDateString()` with a `timeAgo(date: string): string` helper defined at the top of `FlowchartCard.tsx`. Logic: diff = now - date; if < 60s → "just now"; < 60m → "X minutes ago"; < 24h → "X hours ago"; < 7d → "X days ago"; else → `date.toLocaleDateString('en-US', { month: 'short', day: 'numeric' })`. No external library needed.
- **Language badge:** tinted variant — wrap badge with a `data-lang` span and use conditional class: amber/blue/green text + matching `bg-*/10` background using Tailwind arbitrary values.
- **Delete action:** remove `opacity-0 group-hover:opacity-100` delete button. Replace with a `MoreHorizontal` icon button (top-right, `absolute`) that toggles a plain `useState` boolean. When open, render a `div` with `absolute top-8 right-0 z-10 w-32 bg-popover border border-border rounded-md shadow-lg py-1` containing two `button` rows: "Open" and "Delete". Close on outside click via a `useEffect` + `mousedown` listener. Do NOT install shadcn DropdownMenu — it is not in the project.

### Empty State
Replace bare text with:
```
[FileCode2 icon — 48px, text-muted-foreground/40]
Your canvas is empty
Create your first flowchart to get started.
[New flowchart button]
```
Centered, `py-24 flex flex-col items-center gap-3`.

## Section 3 — Editor Toolbar (`components/editor/EditorToolbar.tsx`)

### Button Groups with Dividers
Layout left→right with `w-px h-5 bg-border shrink-0` dividers between each group:

| Group | Contents |
|-------|----------|
| Nav | `← Dashboard` (ChevronLeft icon) |
| File | New (Plus), Save (Save icon), Save As (SaveAll icon) |
| Title | Inline rename input or clickable label |
| Edit | Undo (Undo2), Redo (Redo2), Language selector |
| View/Share | History (Clock), Share/Unshare (Link/LinkOff), Copy link (Copy), PNG (Download) |
| Danger | Delete (Trash2, `text-destructive/70 hover:text-destructive`) |

### Save Button State
- Default (no changes): `variant="ghost"` with Save icon
- Unsaved changes: `variant="secondary"` + `•` prefix character in label — visually distinct, not alarming

### Title Rename Affordance
- Not-editing state: add `hover:border-b hover:border-dashed hover:border-muted-foreground` on the `<button>` to hint it's editable
- Keep existing `autoFocus` + blur-to-save behavior

### Icon Pairing
All toolbar buttons pair text with icon. Icon is `size-3.5` (`14px`), placed before label text with `gap-1.5`.

### Delete Placement
Far-right, after a final divider. Style: `text-destructive/70 hover:text-destructive hover:bg-destructive/10`.

## Section 4 — Auth Pages (`app/(auth)/login/page.tsx` + `register/page.tsx`)

### Branded Header (above card)
Insert above the `<div className="w-full max-w-sm ...">` card:
```tsx
<div className="text-center mb-8">
  <Link href="/" className="text-2xl font-bold tracking-tight">Code2Flow</Link>
  <p className="text-sm text-muted-foreground mt-1">Turn code into flowcharts</p>
</div>
```

### Card Refinements
- Border: replace `border` with `border ring-1 ring-border/40 shadow-xl`
- Top accent: add `border-t-2 border-primary/20` (subtle brand stripe)
- Padding: `p-8` → `p-10`

### Form Improvements
- **Password field:** add `Eye`/`EyeOff` toggle button (`absolute right-3 top-1/2 -translate-y-1/2`) inside a `relative` wrapper div. Toggle `type="password"` ↔ `type="text"`.
- **Submit button loading:** show `<Loader2 className="size-4 animate-spin" />` icon before label text when `loading === true`.
- **Error message:** prefix with `<AlertCircle className="size-4 shrink-0" />` in a `flex items-center gap-1.5` wrapper.
